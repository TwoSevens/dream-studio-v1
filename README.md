# Dream Studio

## What is Dream Studio?

It is the project I've always wanted to make, in one form or the other. I'm not sure I'll have the time for this implementation, but it's still worth the shot. 

Dream Studio is about generating stories. You set up a world and play as one of the actors in it. The engine is designed in a way that makes emergent behavior easy to occur (using AI). 

The central idea of this form of Dream Studio is to rely on LLMs as the brains of actors, while the engine handles hard world rules. For example, the LLM can try to "wear a coat." But if there is no coat nearby, the engine wouldn't allow that action. 

## Why LLMs?

When I first thought of Dream Studio, LLMs weren't that popular. There was that one chatbot app that I was amused by, but it wasn't at the level where I'd think it could do a complex task. So, my idea was to actually use behavior trees, lots of them, and hope that emergent behaviors occur. This isn't impossible, but it'd be very difficult.

But now that LLMs are getting better and cheaper, using them in place of a super complicated behavior tree sounds like the right choice to me. This adds another layer of unpredictability, and it also allows the actors to speak to each other!!! This isn't something you can easily do with a behavior tree.
